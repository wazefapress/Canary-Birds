# 🐤 عالم الكناري وهجينه (Canary Birds App)

![GitHub license](https://img.shields.io/github/license/wazefapress/canary-birds?color=0ba5df)
![GitHub stars](https://img.shields.io/github/stars/wazefapress/canary-birds?color=0ba5df)
![PWA Ready](https://img.shields.io/badge/PWA-Ready-success?color=0ba5df)

تطبيق ويب تقدمي (PWA) وموسوعة تفاعلية شاملة مخصصة لمربي وهواة الطيور المغردة (الكناري، الحسون، والبندوق). يهدف التطبيق إلى تقديم دليل علمي وعملي مبسط لخطوات التربية، التهجين، التغذية، ونظام الإضاءة والتدريب.

---

## 🌟 الميزات الرئيسية

* **📱 تطبيق ويب تقدمي (PWA):** يدعم التثبيت المباشر على الأجهزة والعمل بدون اتصال بالإنترنت (Offline Mode).
* **🎨 تصميم متجاوب (Responsive UI):** واجهة خفيفة ومريحة للعين تعتمد على ألوان عصريّة مع دعم كامل للغة العربية (RTL).
* **⚡ مشاركة سريعة (Web Share API):** إمكانية مشاركة رابط التطبيق أو نسخه بنقرة زر واحدة مع دعم متوافق لجميع المتصفحات.
* **🔍 مهيأ لمحركات البحث (SEO & Open Graph):** متوافق كلياً مع معايير SEO، ويحتوي على خريطة الموقع `sitemap.xml` والبيانات المنظمة `Schema.org`.
* **❓ نظام أسئلة تفاعلي (Accordion FAQ):** عرض القوائم والأسئلة الشائعة بطريقة منسدلة وسلسة.

---

## 📂 هيكلية المشروع

```text
canary-birds-app/
│
├── index.html        # الصفحة الرئيسية
├── canary.html       # قسم طائر الكناري وأنواعه
├── hasoon.html       # قسم طائر الحسون وتحديد الجنس
├── breed.html        # فهرس التكاثر والتهجين
├── tahjeen.html      # خطوات إنتاج البندوق (الهجين)
├── system.html       # نظام العناية، الإضاءة، والحرارة
├── train.html        # طرق التدريب وتسميع الفراخ
├── qa.html           # الأسئلة الشائعة (سؤال وجواب)
├── gift.html         # صفحة الإهداء
│
├── style.css         # ملف التنسيقات الموحد
├── app.js            # ملف البرمجيات والتفاعل
├── sw.js             # ملف الـ Service Worker للتخزين المؤقت
├── manifest.json     # إعدادات تطبيق الـ PWA والتثبيت
├── sitemap.xml       # خريطة الموقع لمحركات البحث
└── robots.txt        # توجيهات أرشفة محركات البحث
```
🛠️ التقنيات المستخدمة
HTML5 / CSS3 (Vanilla CSS Variables)

JavaScript (ES6+ / PWA / Service Workers)

FontAwesome 4.7.0 (للأيقونات)

Schema.org / JSON-LD (للبيانات المنظمة)
